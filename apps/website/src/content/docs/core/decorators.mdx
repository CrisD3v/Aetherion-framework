In Aetherion, decorators are the single source of truth for both your application logic and your cloud infrastructure. This reference provides the exact typings and usage for all available decorators across the framework.

---

## Core Decorators (`@aetherionfw/core`)

### `@LambdaController()`
Marks a class as a serverless controller and defines the AWS Lambda properties.

**Signature**: `@LambdaController(metadata: ControllerMetadata)`

**Properties (`ControllerMetadata`)**:
- `lambdaName` (string): **Required.** The logical name of the Lambda function.
- `runtime` (string): The AWS Lambda runtime (default is typically inferred, e.g., `nodejs20.x`).
- `memorySize` (number): The memory allocated to the function in MB (e.g., `256`, `512`).
- `timeout` (number): The function execution timeout in seconds.
- `layers` (string[]): Array of ARNs for Lambda layers to attach.
- `apiGateway` (string): The logical name of the API Gateway to bind the routes to.

```typescript
@LambdaController({
  lambdaName: 'users-api',
  memorySize: 512,
  timeout: 30,
  apiGateway: 'main-api'
})
export class UserController {}
```

### `@Handle()`
Marks a method as the entry point for the Lambda invocation.

**Signature**: `@Handle(options?: { timeout?: number; memorySize?: number })`

*Note: Overrides the `timeout` or `memorySize` defined at the controller level.*

### `@Route()`
Binds the method to an API Gateway route.

**Signature**: `@Route(metadata: RouteMetadata)`

**Properties (`RouteMetadata`)**:
- `method` (string): **Required.** HTTP method (`GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `ANY`).
- `path` (string): **Required.** The URL path (e.g., `/users/{id}`).
- `authorizer` (string): The ID or logical name of an API Gateway authorizer.

```typescript
@Handle()
@Route({ method: 'GET', path: '/users' })
async listUsers() {}
```

### `@SqsTrigger()`
Triggers the Lambda function from an SQS Queue instead of API Gateway.

**Signature**: `@SqsTrigger(queueName: string, options?: any)`

```typescript
@Handle()
@SqsTrigger('image-processing-queue', { batchSize: 10 })
async processQueue(event: any) {}
```

### `@IamPermissions()`
Grants the Lambda function specific IAM permissions. Can be applied to a class or a specific method.

**Signature**: `@IamPermissions(permissions: Record<string, any>)`

```typescript
@IamPermissions({
  actions: ['dynamodb:PutItem', 'dynamodb:GetItem'],
  resources: ['arn:aws:dynamodb:*:*:table/UsersTable']
})
export class UserController {}
```

### `@UseMiddlewares()`
Attaches middlewares to intercept and process requests before they reach the handler. Can be applied to a class or method.

**Signature**: `@UseMiddlewares(...middlewares: Type<Middleware>[])`

```typescript
@UseMiddlewares(AuthMiddleware, LoggingMiddleware)
async secureEndpoint() {}
```

### `@Injectable()`
Marks a class as a provider that can be injected as a dependency.

**Signature**: `@Injectable()`

### `@Module()`
Groups related controllers, providers, and infrastructure.

**Signature**: `@Module(metadata: ModuleMetadata)`

**Properties (`ModuleMetadata`)**:
- `name` (string): **Required.** The module logical name.
- `imports` (any[]): Other modules to import.
- `providers` (any[]): Injectable services.
- `controllers` (any[]): Lambda controllers.
- `infra` (any[]): Infrastructure classes.

## Infrastructure Decorators (`@aetherionfw/core`)

These decorators are used to provision AWS resources declaratively. They are typically placed in a class marked with `@Infra()`.

### `@Infra()`
Marks a class as an infrastructure definition container.

### `@ApiGateway()`
Provisions an API Gateway.

**Signature**: `@ApiGateway(props: ApiGatewayMetadata)`

**Properties (`ApiGatewayMetadata`)**:
- `name` (string): **Required.** Logical name.
- `type` (`'REST' | 'HTTP'`): **Required.** Type of gateway.
- `description` (string): API description.
- `stageName` (string): Deployment stage (e.g., `prod`, `dev`).
- `corsEnabled` (boolean): Enable CORS default behavior.
- `corsOrigins` (string[]): Allowed CORS origins.

### Resource Decorators
All resource decorators share a similar signature: `@ResourceDecorator(props)`

- `@S3Bucket({ name: string; versioned?: boolean; private?: boolean })`
- `@DynamoTable({ name: string; partitionKey: any })`
- `@SqsQueue({ name: string; visibilityTimeout?: number; deadLetterQueue?: string })`
- `@KmsKey({ alias?: string; description?: string })`
- `@SsmParameter({ name: string; value: string; type?: string })`
- `@EventBridgeRule({ name: string; scheduleExpression?: string })`
- `@CloudFrontDistribution({ originDomain: string })`
- `@CognitoUserPool({ name: string })`
- `@Vpc({ name: string; cidr: string; natGateways?: number })`
- `@IamRole({ name: string; assumedBy: string })`
- `@RdsInstance({ engine: string; size: string; dbName: string })`

```typescript
@Infra()
export class MyInfra {
  @S3Bucket({ name: 'my-uploads-bucket', versioned: true })
  uploadsBucket: any;

  @DynamoTable({ name: 'Users', partitionKey: { name: 'id', type: 'S' } })
  usersTable: any;
}
```

## OpenAPI Decorators (`@aetherionfw/docs`)

Use these decorators on your controllers to automatically generate Swagger documentation.

### `@ApiTag()`
Groups endpoints in the Swagger UI.

**Signature**: `@ApiTag(name: string, description?: string)`

### `@ApiOperation()`
Documents the endpoint's purpose.

**Signature**: `@ApiOperation(metadata: ApiOperationMetadata)`

**Properties (`ApiOperationMetadata`)**:
- `summary` (string): A short summary.
- `description` (string): Detailed description.
- `deprecated` (boolean): Mark endpoint as deprecated.

### `@ApiResponse()`
Documents the expected HTTP response.

**Signature**: `@ApiResponse(metadata: ApiResponseMetadata)`

**Properties (`ApiResponseMetadata`)**:
- `status` (number): HTTP status code (e.g., `200`, `404`).
- `description` (string): Explanation of the response.
- `type` (any): The expected return type/schema.

### `@ApiProperty()`
Documents properties within Data Transfer Objects (DTOs).

**Signature**: `@ApiProperty(metadata: Omit<ApiPropertyMetadata, 'name'>)`

**Properties (`ApiPropertyMetadata`)**:
- `type` (string): The data type (e.g., `'string'`, `'number'`, `'boolean'`).
- `description` (string): Property description.
- `required` (boolean): Whether the property is mandatory.
- `example` (any): An example value.

```typescript
export class CreateUserDto {
  @ApiProperty({ type: 'string', required: true, example: 'john@doe.com' })
  email: string;
}
```
