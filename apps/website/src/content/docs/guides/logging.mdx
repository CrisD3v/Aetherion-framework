Standard `console.log` statements in AWS Lambda can be difficult to parse and search in CloudWatch. Aetherion provides a structured JSON logger via the `@aetherionfw/logger` package.

## The `@Logger()` Decorator

You can inject the framework logger directly into your services and controllers. The logger automatically attaches contextual execution data, including native AWS Lambda variables such as the trace ID (`_X_AMZN_TRACE_ID`) and the function name (`AWS_LAMBDA_FUNCTION_NAME`).

```typescript
import { LambdaController, Route, Handle } from '@aetherionfw/core';
import { Logger, ILogger } from '@aetherionfw/logger';

@LambdaController({ lambdaName: 'user-api' })
export class UserController {
  constructor(@Logger() private readonly logger: ILogger) {}

  @Handle()
  @Route({ method: 'GET', path: '/' })
  async getUsers() {
    this.logger.info('Fetching all users from the database');
  }
}
```

## Log Levels and Context

The logger exposes the four standard log levels. Each level accepts a message and an optional context object to append structured data to your log.

```typescript
// Standard information
this.logger.info('User created', { userId: '123', role: 'admin' });

// Warnings
this.logger.warn('Quota limit approaching', { currentUsage: 95 });

// Errors
try {
  // ...
} catch (error) {
  this.logger.error('Failed to process payment', { error: error.message, transactionId: 'abc' });
}

// Debugging
this.logger.debug('Payload received', { payload });
```

### Debug Level Behavior
Messages logged using `this.logger.debug()` will only be printed to the console if the `DEBUG` environment variable is defined, or if the deployment environment (`AETHERION_STAGE`) is not `prod`. In production, these logs are automatically silenced to reduce costs and noise in CloudWatch.

## CloudWatch Logs Insights Queries

Since the output format is single-line flat JSON, you can easily use **CloudWatch Logs Insights** in AWS to filter and structure complex searches.

An example query to find all errors grouped by their source function:

```text
fields @timestamp, level, message, awsRequestId, error
| filter level = "ERROR"
| sort @timestamp desc
| limit 20
```
