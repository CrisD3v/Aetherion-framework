Aetherion te permite aprovisionar buckets S3 de forma nativa a través del código de tu aplicación utilizando los decoradores de `@Infra`.

## Aprovisionando un Bucket

Para aprovisionar un bucket S3, usa el decorador de propiedad `@S3Bucket` dentro de una clase anotada con `@Infra()`.

```typescript
// src/infra/storage.infra.ts
import { Infra } from '@aetherionfw/core';
import { S3Bucket } from '@aetherionfw/core/decorators/infra.decorator';

@Infra()
export class StorageInfra {
  
  @S3Bucket({ name: 'my-app-uploads', versioned: true, private: true })
  uploadsBucket!: any;
}
```

Cuando despliegues, Aetherion generará automáticamente el código CDKTF equivalente para este bucket y lo aprovisionará en tu cuenta de AWS. ¡Asegúrate de incluir `StorageInfra` en la declaración de tu `@Module()`!

## Lectura y Escritura

Debido a que Aetherion ejecuta Node.js estándar en AWS Lambda, puedes interactuar con el bucket utilizando el SDK oficial de AWS (`@aws-sdk/client-s3`).

Solo asegúrate de otorgarle al método de tu controlador los `@IamPermissions` correctos.

```typescript
import { LambdaController, Handle, Route, IamPermissions } from '@aetherionfw/core';
import { S3Client, PutObjectCommand } from '@aws-sdk/client-s3';

@LambdaController({ lambdaName: 'upload-api' })
export class UploadController {
  private s3 = new S3Client({});

  @Handle()
  @Route({ method: 'POST', path: '/upload' })
  @IamPermissions({
    actions: ['s3:PutObject'],
    resources: ['arn:aws:s3:::my-app-uploads/*']
  })
  async handleUpload(event: any) {
    await this.s3.send(new PutObjectCommand({
      Bucket: 'my-app-uploads',
      Key: `file-${Date.now()}.txt`,
      Body: event.body
    }));
    return { success: true };
  }
}
```
